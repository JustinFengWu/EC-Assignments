How to run the codes for each exercise:

The file structure follows exactly as required in the assignment information.

For ex1:

    run ` python final/code/ex1/exercise1.py ` to execute the program.
    
    To change problem instances executed, modify lines 127-137.
    To change budget and number of rus, modify lines 139-140.

For ex2:

    run ` python final/code/ex2/exercise2.py ` to execute the program.
    
    To change problem instances executed, modify lines 93.
    To change budget and number of rus, modify lines 6-7.

For ex3:

    run ` python final/code/ex3/exercise3.py ` to execute the program.
    
    Lines 275-276 determines whether to run MOE, SOE, or both.
    To change problem instances, population size, budget size and number of runs, modify lines 14-17

There are no new algorithms to be ran for exercise 4.
