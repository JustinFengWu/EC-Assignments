

Exercise 2: the code can be easily executed by running " python ../three_algorithms.py " in bash terminal.
All of the functions will be automatically run through all three algorithms and written into a data folder in 
/code/ex2/data. which algorithms are ran can be changed on lines 88-92. Which functions to be tested can be 
changed on line 85.

Exercise 4: The code can be easily executed by running " python ../implementation.py " in bash terminal.
The code will automatically rrun through and written into a data folder in /code/ex4/data. 

Exercise 5 : The Ioh module needs to be installed in order to execute the own_aco.py file. That can be done
directly into the CLI or using a virtual envionment. Below are the steps that needs to be followed to execute
using virtual environment. Should be done inside the root directory :- 
> python -m venv venv
> source venv/bin/active (To activate the virtual environment) 
Once the virtual environment is setup and activated, go inside the code directory and execute 
own_aco.py file using :- python ex5/own_aco.py
This installs all the necessary data files.
